# Contribution Guidelines

Please ensure your pull request adheres to the following guidelines:

- Search previous entries before adding a new one — duplicates will be closed.
- Add links through pull requests. One roadmap per pull request, please.
- Items within a category should be sorted alphabetically.
- Use the format: `- [Name](link) - Description.`
- The description should start with an uppercase letter, end with a period, and be clear, concise, and non-promotional.
- Only free-to-access roadmaps are accepted (a resource can offer paid extras, but the core roadmap must be viewable without payment or a login wall).
- New categories are welcome if a roadmap doesn't fit an existing one — open an issue first to discuss.
- If you're affiliated with (or the owner of) the resource you're adding, please disclose that in the pull request description.

Thanks for contributing!
